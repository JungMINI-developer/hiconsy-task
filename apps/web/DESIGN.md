# DESIGN.md — 실제 구현된 시각 시스템

[docs/design-system.md](./docs/design-system.md)가 구현 **전**에 세운 초안이라면, 이 문서는 구현을 마친 뒤 **코드에 실제로 있는 값**을 기록합니다. 값의 출처는 `src/styles/main.css`(`@theme`)와 `src/components/ui/variants.ts`입니다. 둘이 다르면 코드가 기준입니다.

## 방향

학원 게시판의 종이 시간표처럼, 정보가 줄 맞춰 놓인 차분한 업무 도구.

- 강조색(남색)은 **주요 행동 버튼과 "내 신청" 표시**에만 씁니다. 나머지는 무채색과 상태색입니다.
- 카드는 그림자 대신 1px 테두리로 구분합니다. 그림자는 떠 있는 요소(다이얼로그·메뉴·토스트)에만 씁니다.
- 숫자(시간·인원)는 `tabular-nums`로 자릿수를 맞춥니다.
- 상태는 색만으로 전달하지 않습니다. 모든 배지와 정원 막대에 텍스트가 함께 있습니다.
- Tailwind 기본 팔레트·크기·모서리·그림자는 `initial`로 지워서, 토큰 밖의 값은 클래스로 만들어지지 않습니다.

## 색

OKLCH로 정의합니다. 대비는 OKLCH → sRGB로 변환해 WCAG 공식으로 계산했습니다(배지 배경은 `/10` 투명도를 흰 배경 위에 합성한 값).

### 기본

| 토큰               | 값                      | 용도                                  |
| ------------------ | ----------------------- | ------------------------------------- |
| `canvas`           | `oklch(98.5% 0.004 95)` | 페이지 배경 (약간 따뜻한 흰색)        |

| `line`             | `oklch(90% 0.006 95)`   | 카드 테두리, 구분선                   |
| `line-strong`      | `oklch(78% 0.008 95)`   | 보조 버튼 테두리, 빈 상태 점선        |
| `line-input`       | `oklch(62% 0.008 95)`   | 입력 컨트롤 테두리 (배경 대비 3.64:1) |

| `fg-muted` / `surface`, `canvas`, `sunken` | 6.54 / 6.26 / 5.91 | 4.5         |
| `accent` 텍스트 / `surface`                | 6.00               | 4.5         |

## 타이포그래피

Pretendard Variable(npm self-host, 동적 서브셋). 크기·줄간격·굵기를 하나의 토큰으로 묶었습니다.

| 클래스         | 크기 / 줄간격          | 굵기 | 쓰는 곳                           |
| -------------- | ---------------------- | ---- | --------------------------------- |
| `text-title`   | 24 / 32 (자간 -0.01em) | 700  | 페이지 `h1`                       |
| `text-heading` | 18 / 26                | 600  | 카드 제목, 다이얼로그 제목        |
| `text-body`    | 15 / 24                | 400  | 본문, 입력값                      |
| `text-label`   | 14 / 20                | 500  | 버튼, 폼 라벨, 메뉴, 탭           |
| `text-caption` | 13 / 18                | 400  | 힌트, 에러 문구, 타임스탬프, 배지 |

- 제목은 `text-wrap: balance`, 문단·목록은 `text-wrap: pretty` — 한글 문장 끝 한 글자가 다음 줄로 떨어지는 것을 막습니다.

## 모양·간격·모션

| 항목           | 값                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------- |
| 모서리         | `rounded-sm` 4px (배지·메뉴 항목), `rounded-md` 8px (버튼·입력), `rounded-lg` 12px (카드·다이얼로그)             |
| 그림자         | `shadow-overlay` 하나 — 다이얼로그·드롭다운·셀렉트·토스트                                                        |
| 폭             | 본문 `max-w-content` 960px, 다이얼로그 `max-w-dialog` 448px, 다이얼로그 최대 높이 `max-h-dialog-h` (화면 - 32px) |
| 높이           | 버튼·입력 40px (`h-10`), 작은 버튼 32px, 아이콘 버튼 36px, 메뉴·셀렉트 항목 36px                                 |
| 간격           | 4px 단위. 카드 안쪽 16px(모바일)/20px, 카드 사이 12px, 폼 필드 사이 20px                                         |
| 브레이크포인트 | `sm` 640px (헤더·표 열 전환), `lg` 1024px (카드 2열)                                                             |
| 이징           | `ease-standard` `cubic-bezier(0.2, 0, 0, 1)`                                                                     |
| 지속시간       | 상태 변화 120ms, 다이얼로그 진입 200ms(살짝 위로 + 페이드), 퇴장 120ms, 변경 항목 강조 1.2s                      |
| 줄인 모션      | `prefers-reduced-motion`에서 모든 애니메이션·전환을 1ms로                                                        |

## 검증 결과 (#18)

| 항목      | 방법                                                        | 결과                                                                                        |
| --------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 색 대비   | OKLCH 토큰 → WCAG 대비 계산                                 | 위 표 전부 통과 (2건 수정)                                                                  |
| 슬롭 패턴 | `impeccable detect` (소스 + `/` URL, 1280·320 폭)           | 0건                                                                                         |
| 금지 패턴 | 임의 값·기본 팔레트·그라데이션·이모지 grep                  | 0건 (`transition-[width]` 속성 지정 1건은 값이 아니므로 허용)                               |
| 320px     | 모든 화면을 320px iframe으로 확인                           | 가로 스크롤 없음. 헤더 메뉴 줄바꿈 1건 수정                                                 |
| 키보드    | 역할 선택 → 학생 목록 → 신청 다이얼로그를 키보드만으로 진행 | 순서 자연스러움, 이동 시 `h1` 포커스, 다이얼로그 첫 입력 포커스, Esc로 닫으면 트리거로 복귀 |
| 에러 상태 | API를 내린 상태로 각 화면 진입                              | 실패한 영역에만 에러 + [다시 시도]. 탭 개수가 0으로 보이던 문제 수정                        |

남은 것: VoiceOver로 신청·취소 흐름 확인(accessibility.md), 다크 모드(토큰 구조만 열어 둠).
